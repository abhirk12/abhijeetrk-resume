# Abhijeet Kulkarni Resume Website

Static responsive resume website for GitHub Pages.

## GitHub Pages
1. Create a repository such as `abhijeet-resume`.
2. Upload `index.html`, `style.css`, and the PDF.
3. Go to **Settings → Pages**.
4. Choose **Deploy from a branch → main → / (root)**.
5. Your site will be available at `https://YOUR-USERNAME.github.io/abhijeet-resume/`.

No Node.js, React, build process, or server is required.

## Before publishing
Add your actual email address if you want an email button. The current page intentionally does not invent an email address.
